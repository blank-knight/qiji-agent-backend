# QIJI Agent 后端 — 分步实施文档

> 目标：从零搭建一个干净的 FastAdmin 后端，专门服务 QIJI-agent 客户端
> 技术栈：PHP 8.1 + FastAdmin（ThinkPHP 5）+ MySQL 5.7+ + Nginx
> 核心代码来源：从 GEO 项目中迁移已写好的明文代码（8个文件）
> 预计工作量：1-2 天（含调试）

---

## 总览：一共 7 个阶段

| 阶段 | 内容 | 依赖 |
|------|------|------|
| 1 | 本地搭建干净 FastAdmin 骨架 | 无 |
| 2 | 准备数据库（建库 + 导入基础表 + 追加客户端表） | 阶段1 |
| 3 | 迁移已写好的明文代码（8个文件） | 阶段1 |
| 4 | 用 CRUD 生成器补建后台管理页面 | 阶段2、3 |
| 5 | 配置路由 + API 前缀 | 阶段3 |
| 6 | 本地联调（用 curl 或 Postman 测试所有接口） | 阶段4、5 |
| 7 | 部署到宝塔服务器 | 阶段6 |

## 阶段 1：本地搭建干净 FastAdmin 骨架

GEO 项目有 100 个加密文件 + 82 张表（大部分是 GEO 业务）。在它上面改会持续被 SG 授权问题干扰。新起一个干净项目最省事。

### 步骤 1.1：下载 FastAdmin 完整版

从官方下载完整包（含 thinkphp 框架和 vendor）：
- 官网：https://www.fastadmin.net/download.html
- 选「完整版」(含 vendor，省去 composer install)

或用 Git：
```bash
cd C:\Users\GBJ-1094\Desktop\code
git clone https://gitee.com/fastadminnet/fastadmin.git qiji-admin
```

> 注意：Git 版不含 vendor，需要本地跑 `composer install`。如果嫌麻烦，直接下完整版 zip。

### 步骤 1.2：放到新目录

```
C:\Users\GBJ-1094\Desktop\code\qiji-admin\
├── application/
├── public/
├── thinkphp/
├── vendor/
├── extend/
├── addons/
```

## 阶段 2：准备数据库

### 步骤 2.1：创建空数据库

本地 MySQL 或宝塔 → 数据库 → 添加：

```sql
CREATE DATABASE qiji_admin DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

记下：数据库名 `qiji_admin`、用户名、密码。

### 步骤 2.2：导入 FastAdmin 基础表

FastAdmin 完整包自带安装 SQL：
```
application/admin/command/Install/fastadmin.sql
```

用 phpMyAdmin 或命令行导入这个文件。它会创建约 20 张基础表（fa_admin、fa_user、fa_auth_*、fa_config、fa_version、fa_category 等）。

**这是 FastAdmin 的标准安装表，全部明文无加密。**

### 步骤 2.3：导入客户端专用表

把 GEO 项目里的 [database_client.sql](file:///c:/Users/GBJ-1094/Desktop/code/GEO/web_aigeo.aibridge.cn_20260727_014711_oUo3Ix/geo/application/database_client.sql) 复制到新项目，然后导入。

这个 SQL 做的事：
1. 建 `fa_agent` 表（代理/贴牌）
2. 建 `fa_agent_invite` 表（邀请码）
3. 给 `fa_user` 加 4 个字段（agent_id、api_key_encrypted、is_custom_key、token_expire）
4. 给 `fa_user_score_log` 加 4 个字段（model、input_tokens、output_tokens、request_id）
5. 给 `fa_config` 插入 `token_per_score` 配置项
6. 插入一个测试代理 + 测试邀请码

### 步骤 2.4：配置 .env

在项目根目录创建 `.env`：
```ini
[app]
debug = true
trace = false

[database]
hostname = 127.0.0.1
database = qiji_admin
username = root
password = 你的密码
hostport = 3306
prefix = fa_
```

### 步骤 2.5：确认表已建好

用 phpMyAdmin 看 `qiji_admin` 库，应该有这些关键表：

| 表名 | 来源 | 用途 |
|------|------|------|
| fa_admin | fastadmin.sql | 后台管理员 |
| fa_user | fastadmin.sql + ALTER | 终端用户（已加 agent_id 等字段） |
| fa_user_token | fastadmin.sql | 登录 token |
| fa_user_score_log | fastadmin.sql + ALTER | 积分流水（已加 token 字段） |
| fa_auth_group / rule | fastadmin.sql | 后台权限 |
| fa_config | fastadmin.sql + INSERT | 站点配置（已加 token_per_score） |
| fa_version | fastadmin.sql | 客户端版本管理 |
| fa_agent | database_client.sql | 代理 |
| fa_agent_invite | database_client.sql | 邀请码 |

共约 28 张表，干净。

## 阶段 4：用 CRUD 生成器补建后台管理页面

阶段 3 复制的是「业务逻辑代码」，但后台管理界面（网页 UI）还需要补建。FastAdmin 的 CRUD 生成器可以一键生成。

### 步骤 4.1：创建 agent 模块（代理后台）

FastAdmin 默认只有 admin/api/index 三个模块。agent 模块需要手动加。

在 `application/agent/` 下创建入口文件 `controller/Index.php`（最小骨架）：
```php
<?php
namespace app\agent\controller;
use app\common\controller\Backend;
class Index extends Backend {
    public function index() {
        return $this->view->fetch();
    }
}
```

再创建代理后台的入口文件 `public/agent.php`（复制 GEO 项目的 [agent.php](file:///c:/Users/GBJ-1094/Desktop/code/GEO/web_aigeo.aibridge.cn_20260727_014711_oUo3Ix/geo/public/agent.php)）：
```php
<?php
define('APP_PATH', __DIR__ . '/../application/');
require __DIR__ . '/../thinkphp/base.php';
\think\Route::bind('agent');
\think\App::route(false);
\think\Url::root('');
\think\App::run()->send();
```

### 步骤 4.2：给 fa_agent 表建 CRUD（总后台管理代理）

命令行执行（在项目根目录）：
```bash
php think crud -t agent
```

这会自动生成：
- `application/admin/controller/Agent.php`（总后台管理代理的控制器）
- `application/admin/model/Agent.php`
- `application/admin/view/agent/add.html`、`edit.html`、`index.html`
- 后台菜单 SQL

### 步骤 4.3：给 fa_agent_invite 建菜单

`AgentInvite` 控制器已经在阶段 3 复制好了，但需要在后台菜单里加一个入口。

在总后台（manner.php 或 admin.php）→ 菜单管理 → 添加：
- 名称：邀请码管理
- 控制器：agent_invite
- 所属：代理后台

或用 SQL：
```sql
INSERT INTO `fa_auth_rule` (`type`, `pid`, `name`, `title`, `icon`, `ismenu`, `createtime`, `updatetime`, `weigh`, `status`)
VALUES ('file', 0, 'agent_invite', '邀请码管理', 'fa fa-ticket', 1, UNIX_TIMESTAMP(), UNIX_TIMESTAMP(), 0, 'normal');
```

### 步骤 4.4：给 fa_version 建管理页面

```bash

```

生成客户端版本管理页面。然后添加一条初始版本记录（在后台填）。

## 阶段 5：配置路由 + API 前缀

### 步骤 5.1：API 路由（重要）

客户端调用的接口是 `/api/client/v1/auth/login` 这种格式，但代码实际在 `api/controller/client/Auth.php`。

需要配置路由让 URL 对得上。编辑 `application/route.php`：

```php
return [
    'client/v1/auth/login'     => 'api/client/auth/login',
    'client/v1/auth/register'  => 'api/client/auth/register',
    'client/v1/auth/activate'  => 'api/client/auth/activate',
    'client/v1/quota'          => 'api/client/quota/index',
    'client/v1/quota/report'   => 'api/client/quota/report',
    'client/v1/apikey'         => 'api/client/apikey/index',
    'client/v1/apikey/customize'=> 'api/client/apikey/customize',
    'client/v1/update/check'   => 'api/client/update/check',
];
```

或者不改路由，直接让客户端调用 `/api/client/auth/login`（不带 v1）。两种方式选一种，保持客户端和后端一致。

### 步骤 5.2：Nginx 伪静态（部署时用）

```nginx
location ~* (runtime|application)/ {
    deny all;
}
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php/$1 last;
        break;
    }
}
```

## 阶段 6：本地联调

### 步骤 6.1：启动本地服务

```bash
php think run
# 或用 phpStudy / 宝塔本地版配一个站点
```

访问 `http://localhost:8000/` 确认能打开。

### 步骤 6.2：测试核心接口（用 curl）

**注册（体验模式，无邀请码）**：
```bash
curl -X POST http://localhost:8000/api/client/auth/register \
  -H "Content-Type: application/json" \
  -d '{"mobile":"13800138000","password":"123456"}'
```
期望返回：`code=1, mode=trial`

**注册（正式模式，带邀请码）**：
```bash
curl -X POST http://localhost:8000/api/client/auth/register \
  -H "Content-Type: application/json" \
  -d '{"mobile":"13900138000","password":"123456","invite_code":"AGENT001"}'
```
期望返回：`code=1, agent_id>0`

**登录**：
```bash
curl -X POST http://localhost:8000/api/client/auth/login \
  -H "Content-Type: application/json" \
  -d '{"mobile":"13800138000","password":"123456"}'
```
期望返回：`code=1, token=xxx`

**查询额度**（用上一步拿到的 token）：
```bash
curl http://localhost:8000/api/client/quota \
  -H "Authorization: Bearer <token>"
```

**Token 上报**：
```bash
curl -X POST http://localhost:8000/api/client/quota/report \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","input_tokens":1500,"output_tokens":500,"request_id":"test-001"}'
```
期望返回：`code=1, remaining_score 减少`

**检查更新**：
```bash
curl "http://localhost:8000/api/client/update/check?version=1.0.0"
```

### 步骤 6.3：验证配额继承

1. 后台登录代理（admin/123456，初始 score=1000000）
2. 后台新建用户，给用户加 score=100
3. 检查代理的 score 是否自动减少 100
4. 再给用户减 score=50
5. 检查代理的 score 是否自动增加 50

### 步骤 6.4：验证幂等去重

同一个 request_id 上报两次：
```bash
curl -X POST .../quota/report -d '{...,"request_id":"test-001"}'
curl -X POST .../quota/report -d '{...,"request_id":"test-001"}'
```
第二次应该返回「已上报过」，score 不再扣减。

## 阶段 7：部署到宝塔服务器

### 步骤 7.1：打包上传

把本地 `qiji-admin/` 整个目录打包 zip，上传到服务器：
```
/www/wwwroot/qiji-admin/
```

### 步骤 7.2：创建数据库 + 导入

宝塔 → 数据库 → 添加数据库 `qiji_admin`：
1. 先导入 `fastadmin.sql`
2. 再导入 `database_client.sql`

### 步骤 7.3：配置 .env

编辑 `/www/wwwroot/qiji-admin/.env`，填服务器上的数据库信息。

### 步骤 7.4：宝塔添加站点

- 域名：建议用新域名或子域名（如 `api.aijiqiren.vip`），**不要和 GEO 的 `agent.aijiqiren.vip` 冲突**
- PHP 版本：8.1
- 运行目录：`/public`

### 步骤 7.5：伪静态

粘贴阶段 5.2 的 Nginx 配置。

### 步骤 7.6：权限

```bash
cd /www/wwwroot/qiji-admin
chown -R www:www .
chmod -R 755 .
chmod -R 777 runtime
```

### 步骤 7.7：端口

和 GEO 一样，80/443 被封，用 8888 或其他端口。可以和 GEO 共用 8888（不同域名通过 Nginx server_name 区分），或用不同端口。

### 步骤 7.8：验证

```bash
curl -X POST http://api.aijiqiren.vip:8888/api/client/auth/login \
  -H "Content-Type: application/json" \
  -d '{"mobile":"13800138000","password":"123456"}'
```
