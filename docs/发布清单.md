# 发布清单

> 每次向生产服务器发布前，照此清单逐项勾选。
> 核心原则：**所有测试必须在 `git pull` 之前完成**——pull 的瞬间即全员生效，无法撤回。

---

## 一、冒烟测试（必须全绿）

```bash
# 本地先启动服务
php -S 127.0.0.1:8082 public/router.php

# 运行冒烟测试（约30秒）
./smoke-test.sh
```

覆盖范围（27 项）：

| 类别 | 检查内容 |
|------|---------|
| 服务器存活 | 入口页响应正常 |
| 超管 | 登录 + 控制台/用户/代理/消费记录/角色组/系统配置 7 个核心页面 |
| 贴牌商 | 登录 + 页面 + 积分横幅 + **越权拦截**（系统配置、角色组） |
| 代理 | 登录 + 页面 + 积分横幅 + **越权拦截**（代理列表、系统配置） |
| 客户端 API | 登录 → 查额度 → 查 Key 完整链路 + 无效 token 返回 401 |
| 历史 bug 回归 | 编辑用户带参数路径（.html 后缀 / 数字 ID 段权限匹配） |

**任何一项 FAIL：停止发布，先修复。**

### 自定义测试目标

```bash
BASE_URL=http://test.example.com ./smoke-test.sh   # 测试其他环境
ADMIN_PASS=xxx TIEPAI_USER=yyy ./smoke-test.sh     # 换测试账号
```

## 二、手工补充测试（涉及以下改动时）

冒烟测试只覆盖核心链路，以下改动需额外手工验证：

| 改动类型 | 额外测试 |
|---------|---------|
| 表单/编辑页 | 三个角色各提交一次，确认保存成功 |
| 计费/积分逻辑 | 充值后核对代理反向扣减（配额继承） |
| 新页面/新菜单 | 见下方"权限规则"章节 |
| Session/登录 | 三角色重新登录一遍 |
| 上传功能 | 传一张图确认落盘且可访问 |
| ECharts 图表 | 检查浏览器 Console 无报错、图表有数据 |

## 三、发布步骤

```bash
# 1. 确认本地测试全绿
./smoke-test.sh

# 2. 提交推送
git add <files>
git commit -m "feat/fix: 描述"
git push

# 3. 服务器上
ssh 你的服务器
cd /www/wwwroot/qiji-admin
git pull

# 4.（如有）数据库变更 → 执行升级 SQL
# 5.（如有）清缓存
rm -rf runtime/cache/* runtime/temp/*

# 6. 服务器上跑一次冒烟测试（可用内网地址）
BASE_URL=http://127.0.0.1:8082 ./smoke-test.sh
```

## 四、权限规则速查（新增菜单/页面时必看）

角色组 ID：`1=超级管理员(rules=*)` `2=贴牌商` `3=代理`

新增页面后必须执行：

```sql
-- 1. 插入规则（ismenu=1 显示在侧边栏，=0 仅权限节点）
INSERT INTO fa_auth_rule (type, name, title, icon, ismenu, status)
VALUES ('file', 'agent/invitestats', '邀请码统计', 'fa fa-bar-chart', 1, 'normal');

-- 2. 把新规则 ID 追加给需要的角色组（贴牌=2，代理=3）
UPDATE fa_auth_group SET rules = rules || ',37' WHERE id IN (2, 3);
```

**注意：菜单规则 ≠ 操作权限。** 访问列表页还需要 `xxx/index` 子规则，否则报 "You have no permission"：

```
agent/agent              ← 菜单（ismenu=1）
agent/agent/index        ← 查看（ismenu=0）★ 没有它列表页打不开
agent/agent/add|edit|del ← 操作（ismenu=0）
```

### 当前各组规则基线

| 组 | 规则 |
|----|------|
| 贴牌商(2) | 全部业务功能，**无** 权限管理(auth) / 系统配置(general/config) |
| 代理(3) | 控制台 + 用户管理 + 邀请码 + 统计，**无** 代理管理 / 版本管理 / 权限管理 / 系统配置 |

## 附：常见坑

| 症状 | 原因 | 解决 |
|------|------|------|
| 新菜单不显示 | 规则没加进角色组 | 第四节的 SQL |
| 列表页 no permission | 只有菜单规则，缺 `index` 子规则 | 补子规则 |
| 贴牌能看系统配置 | 手工改 rules 时误加 | 对照基线删掉 35,36 |
| 改了页面没生效 | 浏览器缓存 | Ctrl+Shift+R |
| 本地好的线上挂 | SQLite 与 MySQL 语法差异 | 避免 COMMENT/REPLACE 等 SQLite 特有写法，或上预发验证 |
